# Host adapters

The core commands and artifact contract are identical on every host. Use only the section for the active host.

## Claude Code

Display or open `dashboard.html` using Claude Code's artifact workflow. Its **Share on Blend** button copies the publication prompt after the user confirms the slug. Instruct the user to paste and send that prompt in Claude chat; Claude can then perform the shared publish procedure through an authenticated Blend MCP server. Do not promise direct artifact-to-MCP publishing.
